# 换电脑搬迁说明

> 从一台电脑搬到另一台电脑,照着做,10 分钟搞定。
> 核心就一句:**把 demo 文件夹整个拷过去 + 新电脑装好 Python 和依赖**。

---

## 一、什么时候用这份说明

- 换新电脑 / 换办公电脑
- 同事电脑也要装一套
- 把系统搬到另一台机器

---

## 二、搬迁三步走

### 第 1 步:拷贝整个 demo 文件夹

- 用 U 盘、微信文件助手、网盘、局域网共享都行
- **把整个 `demo` 文件夹拷走,一个文件都别少**
- 放到新电脑任意位置(桌面、D 盘都行,路径随便,系统不依赖路径)
- 里面已经含:程序、数据(`recruit.db`)、机器人配置

> ⚠️ demo 文件夹里的 `config.py` 含有真实 API Key 和机器人 Secret。
> 只拷给信任的同事没问题;如果要发给陌生人/发到网上,先按本文第四节处理。

### 第 2 步:新电脑装 Python(只需一次)

1. 打开 https://www.python.org/downloads/
2. 下载 Windows 版,双击安装
3. **安装时务必勾选「Add python.exe to PATH」**(这步很关键)
4. 点 Install Now,装完即可

### 第 3 步:双击「安装依赖.bat」(只需一次)

1. 在新电脑上,进入拷过去的 demo 文件夹
2. 双击 `安装依赖.bat`
3. 它会自动:检测 Python → 安装企业微信 SDK → 检查机器人配置
4. 看到「全部就绪」就完成了

## 三、日常使用(和原来一模一样)

| 做什么 | 双击哪个 |
| --- | --- |
| 开看板服务 | `启动招聘系统.bat` |
| 收企业微信消息 | `启动智能机器人.bat` |
| 打开看板 | `查看看板.bat` |
| 导出周报 CSV | `导出周报.bat` |

> 每天开机:先双击前两个,两个黑色窗口保持开着;想看了再双击第三个。

---

## 四、注意事项

### 1. 机器人不要两台电脑同时开

机器人和电脑无关,是**绑定企业微信账号**的。数据只要一份,
**固定一台电脑开着机器人**就行,别两台同时开,否则会抢连接。

### 2. 看板只在本机看

看板地址是 `http://127.0.0.1:8080`,只能在那台电脑上自己打开。
想让别人(如领导)远程看,需要部署到服务器(见《企业微信接入部署手册》附录)。

### 3. 发给陌生人前先清理敏感信息

`config.py` 里有真实的 DeepSeek API Key 和机器人 Secret。
如果要把文件夹发到网上或发给不信任的人,先打开 `config.py`,
把 `DEEPSEEK_API_KEY`、`WECOM_BOT_ID`、`WECOM_BOT_SECRET` 三行
的值清空再发;自己用的时候再填回去。

## 五、常见问题

| 问题 | 解决 |
| --- | --- |
| 双击安装依赖.bat 提示「未检测到 Python」 | 先装 Python,安装时勾选 Add to PATH |
| 装完 Python 还是检测不到 | 关掉所有窗口重开;或重启电脑让 PATH 生效 |
| SDK 安装失败 / 很慢 | 网络问题,稍后重试;脚本会自动用清华镜像 |
| 机器人没反应 | 确认只开了一台机器人;两个启动窗口都开着;发消息时 @了机器人 |
| 收消息报 853000 | 刚重新获取 Secret,企微服务端延迟生效,等 5~10 分钟再启动 |
| 新电脑看板是空的 | 说明没带上 `recruit.db`;回旧电脑把整个文件夹重新拷贝一遍 |
