# 招聘数据管家 · Demo 说明

核心零第三方依赖的 AI 招聘数据自动化 Demo(仅企业微信接收需官方 SDK),演示 **"HR 一句话汇报 → AI 解析入库 → 看板实时呈现"** 全链路。

## 快速开始

### 方式一:双击启动(Windows 推荐)

1. 双击 **`启动招聘系统.bat`** → 浏览器打开 http://127.0.0.1:8080 查看招聘看板(漏斗 / 阶段分布 / 趋势 / 明细)
2. 需要收企业微信消息时,再双击 **`启动智能机器人.bat`**

### 方式二:命令行

```bash
cd demo
python seed_demo.py     # 可选:生成一批演示数据
python app.py           # 启动服务
```

浏览器打开 **http://127.0.0.1:8080**。

## 企业微信接收(生产接入)

`wecom_robot.py` 通过智能机器人长连接接收 HR 消息(免费、无需公网 URL/备案域名):

1. 双击 `启动智能机器人.bat`(需先在 config.py 填好 BotID/Secret)
2. HR 在群里 @机器人 发消息,如:
   ```
   @招聘数据助手 张三 过了二面 后端工程师 期望 15k
   ```
3. 自动解析入库并回复确认,刷新看板即可看到新记录实时上屏

> 详细接入步骤见《企业微信接入部署手册.md》。

## 同步腾讯在线文档

```bash
python sync_tencent_docs.py
```

导出 `招聘数据_同步腾讯文档.csv`,在腾讯文档「新建 → 导入 → 上传」即可,免费实现团队共享台账。

## 接入真实大模型(DeepSeek)

编辑 `config.py`,填入:

```python
DEEPSEEK_API_KEY = "sk-xxxxxxxx"
```

启动后自动切换为 DeepSeek 语义解析(中文理解更强、支持一句话多人/多阶段)。
**不填 Key 也不影响运行**:内置规则引擎可解析"姓名+岗位+阶段+状态+薪资"的常见话术。

## 接口一览

| 接口 | 说明 |
| --- | --- |
| `GET /` | 可视化看板 |
| `GET /api/dashboard` | 看板统计 JSON |
| `GET /api/candidates` | 候选人明细 JSON |
| `POST /api/msg` | 接收自然语言消息(核心入口,`wecom_robot.py` 内部调用) |
| `GET /api/export.csv` | 导出 CSV |

> 内网部署即可,招聘数据无需出网;如公司要求强隔离,可将 DeepSeek 换成内网私有化模型(Ollama + Qwen)。
