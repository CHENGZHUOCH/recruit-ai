# 企业微信接入部署手册

> 目标:HR 在企业微信里给「招聘数据助手」发一句话,系统自动 AI 解析入库,看板实时更新。

---

## 0. 方案选型(先看这里)

| 方案 | 可行性 | 说明 |
| --- | --- | --- |
| **A. 智能机器人·长连接** | ✅ **推荐** | 免费;无需公网 URL、无需备案域名。HR 在群里 **@机器人** 发消息即自动入库 |
| **B. URL 回调 + 内网穿透** | ❌ 暂不可行 | 企微要求回调域名**备案主体与企业一致**;免费 cpolar 域名是第三方备案,校验不通过。需公司备案域名才可启用 |

> **为什么 A 能绕过域名墙**:长连接是机器人**主动连**企业微信服务器(WebSocket),消息由企微推送过来,不像回调那样需要企微反过来访问你的公网地址,所以不校验你的域名。
>
> **本文档按方案 A 为主线**;方案 B 的完整步骤保留在文末附录,等公司拿到备案域名后可直接启用。

---

## 1. 整体链路(方案 A)

```
HR 在企业微信群里 @机器人 发消息: "张三 过了二面 后端 期望15k"
        │  智能机器人长连接(WebSocket,无需公网URL/备案)
        ▼
你的电脑: python wecom_robot.py  →  官方 aibot Python SDK
        ├─ 清洗 @机器人 前缀
        ├─ AI 解析(llm_parser,DeepSeek)
        ├─ 写入 SQLite(recruit.db)
        └─ 回复 HR:"✅ 已记录 张三 共 1 条"
                │
                ▼
      python app.py → 看板 http://127.0.0.1:8080 实时更新(共用同一数据库)
```

---

## 2. 前置条件(先确认)

| 条件 | 说明 |
| --- | --- |
| 企业微信已认证 | 管理后台可正常进入 |
| 有管理员权限 | 建智能机器人、拉群需要管理员 |
| 一台常开电脑 | 跑两个脚本,建议公司内网电脑 |
| Python 3 | 已装(本项目用 3.13) |

---

## 3. 第 1 步:创建智能机器人,拿 BotID / Secret

1. 浏览器打开 [企业微信管理后台](https://work.weixin.qq.com/wework_admin),管理员扫码进入
2. 找到 **「智能机器人」**(企业微信自带能力;入口在不同版本略有差异,常见位置:「应用管理」,或「安全与管理 → 管理工具 → 智能机器人」,也可以在企微客户端「工作台 → 智能机器人」)→ **创建智能机器人**
3. 起名 **招聘数据助手**
4. 接入方式选 **「API 模式」→「长连接」**
5. 页面会给出 **BotID** 和 **Secret**,抄下来

> 长连接模式下机器人不需要 URL/Token/EncodingAESKey 那一套,所以没有「域名主体校验」这道关卡。

---

## 4. 第 2 步:配置并启动

### 4.1 填 config.py(本项目已默认填好)

`E:\AI应用方案\demo\config.py` 里已默认填好你的 BotID / Secret,直接用即可:

```python
WECOM_BOT_ID = "aibY6SGt..."   # 长连接 BotID(已填好)
WECOM_BOT_SECRET = "Qovl88..." # 长连接 Secret(已填好)
```

> 只有**更换机器人**(换公司、重建机器人)时才需要改这两行,替换成新的值。

### 4.2 安装 SDK(本项目已装好,可跳过)

如在新机器部署,打开 cmd 执行一次:

```
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple wecom-aibot-python-sdk
```

### 4.3 启动两个脚本

| 脚本 | 作用 | 启动方式 |
| --- | --- | --- |
| 智能机器人 | 收 HR 消息 → 解析入库 → 回复 | 双击 `启动智能机器人.bat` |
| 看板服务 | 网页看板 | 双击 `启动招聘系统.bat`(即 app.py,端口 8080) |

两个窗口都保持开着。

---

## 5. 第 3 步:真机测试

1. 把「招聘数据助手」机器人**拉进 HR 群**(或直接单聊机器人)
2. 在群里 @机器人 发一句:
   ```
   @招聘数据助手 张三 过了二面 后端工程师 期望 15k 三面约周四
   ```
3. 机器人回复:`✅ 已记录 张三 共 1 条,看板已更新`
4. 电脑浏览器打开 http://127.0.0.1:8080 → 点「刷新」,看板出现「张三」,来源「企业微信智能机器人」→ **全链路跑通!**

> 多个人一起发、一次说多人,都支持(会自动拆成多条)。

## 6. 常见问题排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 启动 bat 报「缺少依赖」 | 没装 SDK | 执行 4.2 的 pip 命令 |
| 启动 bat 提示「请先填写 BotID」 | config.py 没填 | 按 4.1 填写并保存 |
| 群里 @机器人 没反应 | ①机器人没拉进群 ②机器人进程没启动 | 确认群里有机器人、`启动智能机器人.bat` 窗口开着 |
| 启动报 853000(密钥无效) | 刚重新获取 Secret,企微服务端延迟生效 | 等 5~10 分钟再启动;或后台重新「获取」一次新 Secret |
| 收到消息但机器人不回复 | 回复类型不支持 text(40008) | 已改用 markdown 修复;确认启动的是最新版代码 |
| 机器人回复「未能识别」 | 话术太口语/没有姓名阶段 | 尽量用「姓名+阶段+岗位+薪资」格式 |
| 看板打不开 | app.py 没启动 | 双击 `启动招聘系统.bat` |
| 机器人偶尔断开 | 网络波动 | SDK 会自动重连;可把机器人进程设为开机自启 |

## 7. 安全加固(建议后续做)

- **限可见范围**:智能机器人尽量只拉进 HR 相关群,减少无关消息。
- **数据隔离**:候选人信息敏感,正式用建议迁到公司内网专机。
- **加白名单**:可在 `wecom_robot.py` 里校验发送人 `body["from"]["userid"]`,只接受 HR 部门成员的消息。

## 附录:方案 B —— URL 回调 + 内网穿透(需公司备案域名)

> ⚠️ 该方案被企微「域名主体校验」拦截:回调 URL 的域名**备案主体必须与企微认证主体一致**。免费 cpolar 隧道域名(cpolar 公司备案)不满足。**只有拿到公司自己的备案域名后才能启用**,届时:
> - 用 cpolar 付费版(约 25 元/月)绑定公司域名,或直接上云服务器
> - 按企微回调协议重新实现接收层(URL 验证 + 消息解密),接入 `llm_parser` 解析入库
> - 本方案代码此前已移除,启用时按企微文档重新编写即可

### B1. 内网穿透(cpolar)安装

1. https://www.cpolar.com 注册免费账号 → 下载 Windows 版安装
2. 打开 cpolar 终端登录 token:
   ```
   cpolar authtoken <你的token>
   ```
3. 起一条指向本机服务的隧道(把服务端口暴露到公网),获得公网地址。

### B2. 后台配置回调

企微后台 → 应用管理 →「招聘数据助手」→ 接收消息 → 设置 API 接收:

| 配置项 | 填什么 |
| --- | --- |
| URL | `https://公司域名/wecom` |
| Token | 自定义一串,如 `myRecruit2026`,与接收层代码一致 |
| EncodingAESKey | 随机生成(明文模式用不到) |

加解密方式选「明文模式」→ 保存,企微会发一次 URL 验证,「验证成功」即打通。
