# 招聘数据管家 · 小白使用手册

> 只需要会用鼠标双击、会打字,跟着本手册就能用。
> 这套系统帮你做的就一件事:**你在企业微信里说一句话,它自动记下来,还能自动生成看板和表格。**

---

## 一、开机三件事(每天到岗后)

> 记住一句话:**两个黑色窗口都得开着**,系统才正常工作。

1. 找到文件夹 `E:\AI应用方案\demo`
2. **双击** `启动招聘系统.bat` → 会弹出一个黑色窗口,显示
   `招聘数据管家已启动` 就对了
3. **双击** `启动智能机器人.bat` → 再弹出一个黑色窗口,显示机器人已连接

✅ 两个窗口都**保持开着,别关、别点×**,最小化即可。

> 想确认是否正常?随便双击一下 `查看看板.bat`,浏览器能打开看板就说明系统在工作。

---

## 二、每天怎么汇报(最常用)

打开企业微信,找到**有机器人的那个群**(或者和机器人单独聊天)。

> 注意:发送前一定要 **@招聘数据助手**。

### 一句话格式(照着说就行)

```
@招聘数据助手 张三 过了二面 后端工程师 期望15k 三面约周四
```

机器人会回复:

```
✅ 已记录 张三 共 1 条,看板已更新
```

**看到这个就是成功了**,别的什么都不用管,数据已经自动记进系统。

### 常用话术模板(直接复制改名字)

| 想说什么 | 就发这句 |
| --- | --- |
| 一个人过了一面 | `@招聘数据助手 张三 过了一面 后端工程师 期望15k` |
| 一个人进了二面 | `@招聘数据助手 李四 通过二面 前端工程师 12k` |
| 发了 Offer | `@招聘数据助手 王五 offer了 产品经理 18k 周五入职` |
| 有人不合适淘汰 | `@招聘数据助手 赵六 简历不合适 淘汰` |
| 一次说好几个人 | `@招聘数据助手 张三过二面后端15k 李四offer前端12k 王五淘汰` |

**关键要素记牢:姓名 + 阶段 + 岗位 + 期望薪资 + (备注)**,说得越清楚,记得越准。

## 三、怎么看数据

1. **双击** `查看看板.bat`(或浏览器打开 `http://127.0.0.1:8080`)
2. 看板会自动刷新,能看到:
   - **招聘漏斗**:投递 → 面试 → Offer → 入职,每个环节人数
   - **阶段分布**:当前所有人都在哪个环节
   - **趋势图**:最近每天的进展
   - **候选人明细**:所有人的完整记录(姓名/岗位/薪资/备注)

> 记错了也不用慌:明细表旁边有编辑/删除按钮,鼠标点几下就能改。

## 四、怎么做周报(每周五)

1. **双击** `导出周报.bat` → 黑色窗口提示
   `已导出(可直接上传腾讯在线文档): 招聘数据_同步腾讯文档.csv`
2. 找到新生成的文件 `招聘数据_同步腾讯文档.csv`(就在 demo 文件夹里)
3. 打开腾讯文档 → **新建 → 导入 → 上传**这个文件 → 选「替换」
4. 一份团队共享的招聘台账就自动建好了,以后每周导一次、替换一次即可

> 想发到群里/发给领导,直接把这个 CSV 发给对方,用 Excel 打开即可。

## 五、常见小问题

| 遇到的情况 | 怎么办 |
| --- | --- |
| 机器人不回复 | 先看两个黑色窗口是不是都开着;再看群里是不是 @了机器人 |
| 窗口关掉了 | 重新双击 `启动智能机器人.bat` 和 `启动招聘系统.bat` |
| 回复「未能识别」 | 话术尽量按「姓名 阶段 岗位 期望薪资」格式再说一遍 |
| 看板打不开 | 双击 `启动招聘系统.bat`,等出现「已启动」再刷新浏览器 |
| 记错了一条记录 | 打开看板 → 候选人明细 → 找到这条 → 编辑或删除 |
| 电脑重启后 | 把开机三件事重新做一遍即可 |
