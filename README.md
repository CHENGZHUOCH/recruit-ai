# AI 对话式招聘数据管家

> 把「HR 手动填表」升级为「AI 听懂人话并自动记录」——企业微信里发一句话,自动解析入库,看板实时呈现。
> 本仓库为**可直接运行、可在线预览**的 AI 应用 Demo,核心零第三方依赖。

## 一句话亮点

HR 在企业微信群里 @机器人 发一句:「张三 过了二面 后端工程师 期望15k 三面约周四」,
AI 大模型自动解析为结构化数据写入数据库,招聘看板实时更新,替代手工录入与统计。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| AI 语义解析(核心) | DeepSeek 大模型把口语化汇报解析成结构化 JSON,一句话可拆分多人、多阶段 |
| 规则引擎兜底 | 不配 API Key 也能跑:锚点法识别姓名、岗位/阶段/状态词典归一化,保证开箱即用 |
| 企业微信智能机器人 | 免费、免公网/免备案,群里 @机器人 发消息即自动入库(长连接方案) |
| 实时可视化看板 | 招聘漏斗 / 阶段分布 / 近14天趋势 / 候选人明细,30 秒自动刷新 |
| 腾讯文档同步 | 一键导出 CSV,直接导入腾讯在线文档,形成团队共享台账 |
| 零依赖可运行 | 核心 Python 标准库实现,无需安装任何第三方包 |

## 在线预览(无需部署,浏览器直接打开)

[AI 招聘数据看板(在线 Demo)](https://chengzhuoch.github.io/recruit-ai/demo/dashboard.html)

> 在线预览为内置演示数据;本地运行则展示你录入的实时数据。

## 快速开始(5 分钟)

```bash
git clone https://github.com/CHENGZHUOCH/recruit-ai.git
cd recruit-ai/demo
python seed_demo.py    # 生成 30 条演示数据
python app.py          # 启动看板服务
```

浏览器打开 http://127.0.0.1:8080

### 启用 DeepSeek AI 语义解析(可选)

编辑 `demo/config.py` 填入:

```python
DEEPSEEK_API_KEY = "sk-xxxxxxxx"
```

不填也能跑:内置规则引擎同样可解析「姓名 + 阶段 + 岗位 + 期望薪资」常见话术。

## AI 实际应用能力演示

| HR 原始说法 | AI 解析结果 |
| --- | --- |
| 今天张三过了一面,后端工程师,期望15k,二面约周四 | `{"name":"张三","position":"后端工程师","stage":"面试","status":"通过","salary":15000,"note":"二面约周四"}` |
| 李四 offer 了,前端,12k,周五入职 | `{"name":"李四","position":"前端工程师","stage":"Offer","status":"通过","salary":12000,"note":"周五入职"}` |
| 王五那个产品经理简历不合适,pass 掉 | `{"name":"王五","position":"产品经理","stage":"淘汰","status":"不通过","note":"简历不合适"}` |

**即使一句话包含多人、多阶段,大模型也能一次性拆分解析**,这是传统表单/正则无法替代的价值。

## 技术架构

```
┌───────────────────────────────────────────────────────────────┐
│                       数据接入层                                │
│   企业微信智能机器人(长连接) / 手动补录 / 批量导入                │
└────────────────────────────┬──────────────────────────────────┘
                             ▼
┌───────────────────────────────────────────────────────────────┐
│                        AI 语义解析层                            │
│   大模型(DeepSeek) 自然语言 → 结构化 JSON                      │
│   ↓ 校验 / 清洗 / 去重 / 枚举归一化(规则引擎兜底)               │
└────────────────────────────┬──────────────────────────────────┘
                             ▼
┌───────────────────────────────────────────────────────────────┐
│                         数据存储层                              │
│                SQLite(候选人/阶段/状态/薪资)                    │
└───────────────┬───────────────────────────────┬───────────────┘
                ▼                               ▼
┌──────────────────────────────┐   ┌──────────────────────────────┐
│   输出层 · 实时同步            │   │   输出层 · 可视化            │
│   腾讯文档同步 / 导出周报      │   │   Web 招聘看板(ECharts)     │
└──────────────────────────────┘   └──────────────────────────────┘
```

## 目录结构

```
.
├── 招聘AI落地方案.md        # 完整落地方案(背景/架构/成本/实施路径)
├── demo/                    # 可直接运行的 Demo
│   ├── app.py               # 看板服务(Python 标准库 HTTP Server)
│   ├── llm_parser.py        # AI 语义解析层(DeepSeek + 规则引擎兜底)
│   ├── storage.py           # SQLite 数据层
│   ├── dashboard.html       # 单文件可视化看板(可静态托管在线预览)
│   ├── wecom_robot.py       # 企业微信智能机器人接入(可选)
│   ├── seed_demo.py         # 生成演示数据
│   ├── config.py            # 配置文件(填 DeepSeek Key)
│   └── *.bat                # Windows 一键启动脚本
└── .gitignore
```
